# Запуск сценариев по расписанию

В серверных редакциях Loginom ([Team](./../compare-editions.md#team), [Standard](./../compare-editions.md#standard) и [Enterprise](./../compare-editions.md#enterprise)) имеется возможность [пакетного выполнения сценариев](./batchlauncher.md). Для запуска пакетного выполнения по расписанию можно использовать встроенный [планировщик задач](./scheduler.md) или сторонний, например, планировщик заданий Windows.
