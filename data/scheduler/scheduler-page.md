# Страница «Планировщик»

В окне *Планировщик* производится добавление, редактирование и удаление задач. Перейти на страницу «Планировщик» можно по нажатию кнопки ![](./../images/icons/app/system-toolbar/controls/system-objects_sliced_18x18_scheduler_disabled.svg) или через [навигацию](./../interface/main-menu.md#imagesiconsappsystem-toolbarcontrolscompasdefaultsvg-navigatsiya) в главном меню.

На панели инструментов доступны следующие команды:

* ![](./../images/icons/common/toolbar-controls/plus_default.svg) **Добавить... (Alt+N)** — открывает окно настройки новой задачи.
* ![](./../images/icons/common/toolbar-controls/edit_default.svg) **Редактировать... (F2)** — открывает окно настройки уже существующей задачи.
* ![](./../images/icons/common/toolbar-controls/clone_default.svg) **Клонировать (Ctrl+D)** — клонирование выбранной задачи с сохранением всех настроек.
* ![](./../images/icons/common/toolbar-controls/run-current_default.svg) **Запустить (F3)** — запуск задачи вручную. Доступно только для задач, для которых разрешено выполнение.
* ![](./../images/icons/common/toolbar-controls/stop_default.svg) **Остановить** — останавливает все сессии для выбранной задачи.
* ![](./../images/icons/common/toolbar-controls/delete_default.svg) **Удалить... (Delete)** — удаляет выбранную задачу.
* ![](./../images/icons/common/toolbar-controls/toolbar-controls_sliced_18x18_journal_default.svg) **Журнал (Shift+J)** — открывает/закрывает [журнал сессий](#zhurnal-sessiy).
* ![](./../images/icons/common/system-objects/sliced_18x18/refresh_default.svg) **Обновить список (Alt+F5)** — добавляет новые/убирает старые, уже удаленные задачи. Также обновляет отображение задач с учётом их актуальных настроек.

> **Примечание:** если клонировать задачу другого пользователя, то запуск клонированной задачи будет выполняться из-под текущего пользователя, который клонировал задачу.

Вышеперечисленные команды можно выполнить через контекстное меню, которое вызывается при нажатии правой кнопки мыши по задаче. При этом добавляются дополнительные действия:

* ![](./../images/icons/blank.svg) **Открыть пакет** — переходит на страницу со сценарием выбранного в настройках задачи пакета.
* ![](./../images/icons/blank.svg) **Открыть узел в пакете** — переходит на страницу со сценарием к узлу, который выбран как запускаемый в настройках задачи.
* ![](./../images/icons/common/toolbar-controls/redo_default.svg) **Показать пакет в папке** — переходит к каталогу в [файловом хранилище](./../location_user_files.md), где расположен запускаемый пакет.
* ![](./../images/icons/blank.svg) **Разрешить/Запретить выполнение** — опция Разрешить выполнение в [настройках задачи](./../scheduler/scheduler.md#dobavlenie-i-nastroyka-zadach).

## Таблица задач

Таблица со списком добавленных задач имеет вид дерева с одним уровнем вложенности. Корнем дерева является строка «Все задачи». Выбрав данную строку, в журнале можно получить информацию по всем завершенным сессиям, в том числе и для удаленных задач. В данной таблице по всем доступным задачам представлена следующая информация:

* **Метка** — название задачи, определенное при добавлении.
* **Пакет** — название и полный путь до запускаемого пакета.
* **Узел** — Имя или GUID запускаемого узла, если выбран не весь пакет.
* **Предыдущий запуск** — дата и время предыдущего запуска задачи.
* **Следующий запуск** — дата и время следующего запуска задачи по расписанию.
* **Владелец** — пользователь, создавший задачу.

Также имеется возможность удалить все задачи, нажав соответствующую кнопку ![](./../images/icons/common/toolbar-controls/delete-all_default.svg) Удалить все... Либо удалить конкретную задачу по кнопке ![](./../images/icons/common/toolbar-controls/delete_default.svg) Удалить. При удалении задачи пользователю будет предложено остановить для неё активные сессии.

> **Примечание:** если в строке таблицы задач текст информации по конкретной задаче имеет серый цвет, то для данной задачи выполнение запрещено.

## Журнал сессий

Посмотреть список активных и завершенных сессий для одной, нескольких или всех задач можно в *Журнале сессий*, который открывается в нижней части окна, если нажать соответствующую кнопку ![](./../images/icons/common/toolbar-controls/toolbar-controls_sliced_18x18_journal_default.svg) на панели или сочетание клавиш *Shift+J*.

Журнал содержит две вкладки:

* **Активные** — список активных сессий для выбранной задачи.
* **Завершенные** — список завершенных сессий для выбранной задачи.

Структура таблицы для активных сессий:

* Метка задачи — соответствует Метке из таблицы задач.
* Номер сессии — номер по порядку.
* **%** — процент выполнения задачи для данной сессии.
* Обработка:
  * ![](./../interface/information-panel-3.png) — прогресс выполнения активной сессии.
* ![](./../images/icons/common/toolbar-controls/stop-all_default.svg) — остановить все сессии.
  * ![](./../images/icons/common/toolbar-controls/stop_default.svg) — остановить конкретную сессию.
* Начало — дата и время запуска сессии.
* Время выполнения — разница между временем запуска и текущим временем.

Структура таблицы для завершенных сессий:

* Метка задачи — соответствует Метке из таблицы задач.
* Номер сессии — номер по порядку.
* Статус — статус завершения сессии.
* Ошибка — указывается текст ошибки в случае ее возникновения.
* Начало — дата и время запуска сессии.
* Окончание — дата и время завершения сессии.
* Время выполнения — разница между временем запуска и окончанием сессии.

В таблице завершённых сессий при клике на ячейку с текстом ошибки открывается окно с подробной информацией об ошибке.
Особенности работы:
* Если в данных ошибки указана временная метка (`ErrTimestamp`), она отображается в окне.
* Если временная метка не указана, отображается текущее время открытия окна.

> **Примечание:** если текст логов сессии имеет серый цвет, то соответствующая ей задача была удалена.

Для журнала имеется возможность сортировки записей по всем полям таблицы завершенных и активных сессий, кроме полей *Обработка* и *Остановить все сессии*.

При нажатии правой кнопки мыши вызывается контекстное меню, содержащее следующие действия:

* ![](../images/icons/blank.svg) Остановить сессию — останавливает выполнение выбранной сессии.
* ![](./../images/icons/common/toolbar-controls/stop_default.svg) Остановить все сессии... — останавливает выполнение всех сессий.
* ![](../images/icons/blank.svg) Перейти к задаче — осуществляет переход к задаче выбранной сессии.

> **Примечание:** время хранения логов Журнала сессий определяется настройкой *Хранение истории планировщика (дней)* в разделе [Администрирование](./../admin/README.md) на странице [Параметры](./../admin/parameters/server-parameters.md).

> **Важно:** перед каждым запуском [Loginom Server](./../components-platform.md#server) выполняется очистка записей завершенных по задачам сессий.
