# ![](./../../images/icons/common/toolbar-controls/filter_default.svg)Фильтр

Позволяет выделить записи, которые удовлетворяют одному или нескольким условиям. Несколько условий объединяются в сложное условие с помощью логических операторов И/ИЛИ.

## Окно настройки

В окне располагается область настройки условий фильтрации в виде таблицы. Каждая строка таблицы представляет собой [условие](./../../processors/transformation/row-filter/filtering-criteria.md) фильтрации либо служебную строку с оператором ИЛИ. Если между условиями нет строки ИЛИ, то считается, что они объединены через логическое И.

Новое условие добавляется нажатием на кнопку ![](./../../images/icons/common/toolbar-controls/plus_default.svg) *Добавить условие*.

На панели инструментов и в контекстном меню доступны следующие команды:
* ![](./../../images/icons/common/toolbar-controls/plus_default.svg) **Добавить условие (Alt+N)** — добавляет новую строку условия.
* **Добавить оператор ИЛИ (Alt+O)** — добавляет логический оператор ИЛИ в конец таблицы с условиями.
* **Добавить оператор ИЛИ выше/ниже** — добавляет логический оператор ИЛИ на одну позицию выше или ниже выделенной строки.
* ![ ](./../../images\icons\common\toolbar-controls\clone_default.svg) **Клонировать (Ctrl+D)** — добавляет новое условие с параметрами, как у выбранного условия, клон добавляется в конец таблицы.
* ![ ](./../../images/icons/common/toolbar-controls/moveup_default.svg) **Переместить вверх (Ctrl+Up)** — поднять условие или логический оператор ИЛИ на одну позицию вверх по списку.
* ![ ](./../../images/icons/common/toolbar-controls/movedown_default.svg) **Переместить вниз (Ctrl+Down)** — опустить условие или логический оператор ИЛИ на одну позицию вниз по списку.

>**Примечание**: Также поля и операторы можно перемещать перетягиванием выше или ниже.

* ![Переносить текст](./../../images\icons\common\toolbar-controls\header-word-wrap_default.svg) **Переносить текст** — активирует перенос слов или блоков текста в колонке *Значение* на следующую строку (но не больше чем на 3 строки), если текст выходит за пределы текущей строки. Более длинные значения можно просматривать с помощью всплывающей подсказки, которая появляется при наведении курсора на поле *Значение*.
* ![Включить фильтр](./../../\images\icons\ext\checkbox-states\checked_default.svg) **Включить фильтр** — если убрать галочку, то будут отключены корректно настроенные условия и  можно посмотреть данные без фильтра. Настроенные фильтры сохраняются в окне настройки.
* ![Удалить все ](./../../images/icons/common/toolbar-controls/delete-all_default.svg) **Удалить все... (Shift+Delete)** — удаляет все имеющиеся условия.
* ![ ](./../../images/icons/common/toolbar-controls/delete_default.svg) **Удалить выражение (Delete)** — удаляет выбранное условие.

В зависимости от условия, [вида](https://help.loginom.ru/userguide/data/datakind.html) и [типа](https://help.loginom.ru/userguide/data/datatype.html) данных поля, значение можно задать с помощью переключателя или выбрать из предлагаемого списка.  Также можно ввести данные с клавиатуры.

Для условий `<`,`<=`,`>`,`>=`,`=`,`<>` значения задаются из выпадающего списка или вручную. Значения добавляются по клавише %kbd Enter %, удаляются — по клавишам %kbd Backspace % или %kbd Delete %.

Для условий *пустой*, *не пустой* значение не задается.

Для условий *в интервале*, *вне интервала* значения границ интервала задаются в появляющемся окне. Добавить значение можно вручную либо из выпадающего списка.

Для условий *содержит*, *не содержит*, *начинается с*, *не начинается с*, *заканчивается на*, *не заканчивается на* добавить значение можно вручную либо из выпадающего списка.

Для условий *в списке*, *вне списка* значения выбираются в окне *Список значений*.

В окне *Список значений* на панели инструментов доступны следующие команды:

* ![](./../../images/icons/common/toolbar-controls\toolbar-controls_18x18_get-column-list_default.svg) **Получить список** — выводит список всех уникальных значений поля. Максимальное количество уникальных значений в списке: 10000.
* ![](./../../images/icons/common/toolbar-controls/toolbar-controls_18x18_check-all_default.svg) **Выбрать все** — выбирает все значения из списка.
* ![](./../../images/icons/common/toolbar-controls/toolbar-controls_18x18_reverse-check_default.svg) **Инвертировать выбор** — деактивирует/активирует выбранное значение активируя/деактивируя все остальные значения. Если не одно значение в списке не выбрано, то при инвертировании выбора, все значения будут активированы и наоборот.
* ![](./../../images/icons/common/toolbar-controls/toolbar-controls_18x18_uncheck-all_default.svg) **Отменить выбор всех** - отменяет все выбранные значения из списка.
* ![](./../../images/icons/common/toolbar-controls/plus_default.svg) **Добавить...** — добавляет новое значение в список.
* ![ ](./../../images/icons/common/toolbar-controls/edit_default.svg) **Редактировать... (F2)** — редактирует добавленное значение.
* ![](./../../images/icons/common/toolbar-controls/copy_default.svg) **Копировать (Ctrl+C)** — копирует выбранное значение из списка.
* ![](./../../images/icons/common/toolbar-controls/paste_default.svg) **Вставить (Ctrl+V)** — вставляет скопированное значение в список.
* ![](./../../images/icons/common/toolbar-controls/filter_default.svg) **Фильтрация** — позволяет найти поле по имени или его части.

При ручном вводе значения доступна вставка из буфера обмена.

После установки настроек фильтрации нужно нажать кнопку ***Фильтровать***.
