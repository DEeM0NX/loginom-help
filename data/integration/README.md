# Интеграция

Механизмы интеграции предназначены для обмена данными между платформой Loginom и сторонними внешними системами. Loginom позволяет взаимодействовать с [веб-сервисами](./web-services/README.md), базами данных и файловыми хранилищами (электронные таблицы, текстовые файлы и т.д.).

> **Важно**:
> для интеграции с некоторыми источниками, например, базами данных и веб-сервисами, необходима предварительная настройка [подключения](./connections/README.md).

Компоненты Loginom для взаимодействия с внешними системами описаны в нескольких разделах:

* [Подключение](./connections/README.md) — этот раздел включает описание подключений с указанием параметров доступа к внешним системам, требуемых для последующего многократного использования.
* [Импорт](./import/README.md) — раздел предназначен для описания узлов извлечения данных из внешних источников с целью их последующей обработки.
* [Экспорт](./export/README.md) —  это раздел, в котором описываются способы передачи обработанных данных во внешние системы для их хранения, использования, передачи или публикации.
* [Веб-сервисы](./web-services/README.md) — данный раздел описывает работу Loginom с веб-сервисами.
