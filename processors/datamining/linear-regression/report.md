# Сводка

Переменные, которые отдает порт *Сводка*, сведены в таблицу:

| Переменная (Метка) | Описание |
|:-------|:-------|
| Всего примеров | Общее число [примеров](https://wiki.loginom.ru/articles/training-sample.html), поданных на вход [модели](https://wiki.loginom.ru/articles/taught-model.html) |
| Всего отобранных примеров | Общее число примеров в обучающем и тестовом множествах |
| Примеров в [обучающем множестве](https://wiki.loginom.ru/articles/training-set.html) | Число примеров, на котором обучается модель |
|Логарифм [функции правдоподобия](https://wiki.loginom.ru/articles/mle.html)|Показывает степень соответствия модели набору данных, на котором она обучается|
| [Коэффициент детерминации](https://wiki.loginom.ru/articles/coefficient-of-determination.html) | Доля дисперсии зависимой переменной, объяснённая регрессионной моделью (изменяется от 0 до 1) |
| [Скорректированный коэффициент детерминации](https://wiki.loginom.ru/articles/coefficient-determ-adj.html) | Отличается от нескорректированного коэффициента детерминации тем, что накладывает штраф за дополнительно вводимые в модель переменные (изменяется от 0 до 1) |
| Стандартное отклонение | Мера отклонения примеров от предсказанных моделью значений |
| Число степеней свободы ошибки | Разность между размером выборки и числом оцениваемых параметров модели |
| [Число степеней свободы модели](https://wiki.loginom.ru/articles/degrees-of-freedom.html) | Число независимо варьируемых [переменных](https://wiki.loginom.ru/articles/attribute.html) модели |
| [F-статистика](https://wiki.loginom.ru/articles/f-test.html) | Статистика F-теста для оценки значимости модели |
| [Информационный критерий Акаике](https://wiki.loginom.ru/articles/aic.html) | Критерий используется для сравнения моделей с разным числом параметров, когда требуется выбрать наилучший набор объясняющих переменных |
| [Информационный критерий Акаике скорректированный](https://wiki.loginom.ru/articles/aicc.html) | Модифицированный критерий Акаике, применяемый для [выборок](https://wiki.loginom.ru/articles/sample.html) малого размера, когда отношение числа содержащихся в ней примеров к числу параметров модели меньше 40 |
| [Информационный критерий Байеса](https://wiki.loginom.ru/articles/bic.html) | Критерий основан на использовании [функции правдоподобия](https://wiki.loginom.ru/articles/plausibility-function.html) и тесно связан с информационным критерием Акаике |
| [Информационный критерий Ханнана-Куинна](https://wiki.loginom.ru/articles/hq.html) | Критерий основан на использовании функции правдоподобия и является альтернативой критериям Акаике и Байеса|
| [P-значение модели](https://wiki.loginom.ru/articles/p-value.html) | Оценка [значимости](https://wiki.loginom.ru/articles/significance-regr.html) модели. Чем меньше P-значение, тем меньше вероятность нулевой гипотезы о том, что нет статистически значимой связи между зависимой и независимыми переменными. Вычисляется по F-статистике. |
| Примеров в [валидационном множестве](https://wiki.loginom.ru/articles/validation-set.html) | Количество примеров в колоде (метод К-fold кросс-валидация) или в итерации ресемплинга ([метод Монте-Карло](https://wiki.loginom.ru/articles/monte-carlo-technique.html)) |
| Число [валидационных разбиений](https://wiki.loginom.ru/articles/cross-validation.html) | Количество колод (метод К-fold кросс-валидация) или итераций ресемплинга (метод Монте-Карло) |
|  Примеров в [тестовом множестве](https://wiki.loginom.ru/articles/test-set.html) | Число примеров, на котором проверяется модель |
