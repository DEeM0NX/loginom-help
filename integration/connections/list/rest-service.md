# ![](./../../../images/icons/common/data-sources/web-rest_default.svg) Подключение REST-сервиса

Задаются параметры подключения, запроса и ответа REST-сервиса. В сценарии эти параметры принимаются узлом [REST-запрос](./../../../processors/integration/rest-request.md) во входном порту *Подключение к REST-сервису*. 

> Примечание: Процесс создания и использования подключений в сценариях описан в разделах:
> * [Настройка подключения](./../README.md#nastroyka-podklyucheniya)
> * [Создание узла подключения в сценарии](./../../../quick-start/database.md#shag-2-sozdanie-uzla-podklyucheniya-v-stsenarii) на примере создания подключения к базе данных. Описанная в статье последовательность действий актуальна для всех подключений.

## Параметры подключения

* **Автоматическая метка** — переключатель режима формирования метки узла. Если выбран режим *Автоматическая метка*, то она формируется по правилу: `REST: URL сервиса`. Если выбран режим *Пользовательская метка* — метка задается пользователем.

* **URL сервиса** — задается адрес отправки запросов к REST-сервису.
* **Метод** — выбирается один из HTTP-методов, используемых при отправке запросов к сервису: GET, DELETE, POST, PUT, PATCH.
* **Тип URL параметров** — из выпадающего списка типа параметров выбирается нужный:
    * [Строка запроса](././rest-parameters-examples.md#ispolzovanie-tipa-url-parametrov-stroka-zaprosa)
    * [Добавление сегментов](././rest-parameters-examples.md#ispolzovanie-tipa-url-parametrov-dobavlenie-segmentov)
    * [Замена](././rest-parameters-examples.md#ispolzovanie-tipa-url-parametrov-zamena)
* **Content-Type запроса** — задается значение заголовка `Content-Type` HTTP-запроса к REST-сервису. Доступен как выбор из списка предопределенных значений, так и ввод произвольного значения. Настройка доступна при выборе методов POST, PUT, PATCH.

* **Допустимый Content-Type ответа** — узел REST-запрос, использующий данное подключение, проверяет тип ответа на соответствие заявленному в данном параметре. При несоответствии типов выходной набор этого узла будет содержать сообщение об ошибке. Данная проверка не осуществляется, если параметр имеет значение `*/*`.

* **Таблица параметров запроса** предназначена для создания и отображения параметров, которые используются для формирования итогового URL запроса. Для каждого параметра определяется *Имя* и *Тип данных*. На панели инструментов таблицы доступны следующие команды:
    
  * ![](./../../..\images\icons\common\toolbar-controls\toolbar-controls_18x18_plus_default.svg) **Добавить URL параметры запроса** — при нажатии на кнопку в таблицу ниже добавляются URL параметры  запроса. Данное действие доступно, если выбраны типы URL параметров *Строка запроса* или *Добавление сегментов*.
  > **Примечание**: На имена параметров не накладываются дополнительные ограничения. Например, имена могут иметь вид: `1имя`, `1name`, `Имя2Name`.

  * ![](./../../..\images\icons\common\toolbar-controls\get-column-list_default.svg) **Получить URL параметры запроса** — заполняет таблицу параметрами, указанными в поле **URL сервиса** с использованием специального синтаксиса `:<имя_параметра>`, например: `:param1`. Данное действие доступно, если выбран тип URL параметров *Замена*.

  * ![ ](./../../../images/icons/common/toolbar-controls/delete-all_default.svg) ![ ](./../../../images/icons/common/toolbar-controls/delete_default.svg) **Удаление** — удаляет выбранные или все параметры.
  
  * ![ ](./../../../images/icons/common/toolbar-controls/moveup_default.svg) ![ ](./../../../images/icons/common/toolbar-controls/movedown_default.svg) **Переместить вверх/вниз**  — изменяет порядок расположения выбранных параметров в таблице.

  >**Важно**: Для типов URL параметров *Строка запроса* и *Добавление сегментов* порядок строк в таблице параметров влияет на итоговый URL: добавление параметров в URL осуществляется в порядке их следования в таблице, таким образом **результирующий запрос зависит от того, в какой последовательности идут параметры**.
  >
  > Для типа *Замена* порядок и место подстановки значений определяются расположением параметров в строке *URL сервиса*.

* **Пример сформированного URL** — нередактируемое поле, демонстрирует пример итогового URL, который получится при текущих параметрах.

* **Аутентификация для выполнения запроса** — настройка, определяющая способ [аутентификации](./auth-type.md), используемый при подключении к REST-сервису.
* **Таймаут подключения (мс)** — максимальное время установки TCP-соединения с сервером в миллисекундах, по истечении которого соединение будет прервано со статусом ошибки. Если параметр равен нулю, то таймаут не ограничен. Следует отметить, что данный параметр **не определяет максимальное время выполнения запроса**.
* **Не проверять сертификат сервера** — если данный флаг установлен, то ошибки при проверке сертификата сервера, к которому производится подключение, игнорируются.

  >**Примечание**: Если в [Параметрах безопасности](./../../../admin/parameters/security-parameters.md) включено *Всегда проверять SSL-сертификаты* или *Всегда проверять сертификаты HTTPS*, то:
  >
  > * настройка *Не проверять сертификат сервера* скрывается в мастере настройки и игнорируется;
  > * сертификат сервера проверяется принудительно для всех TLS/HTTPS-соединений.

* **Комментарий** — в этой форме можно оставить любую справочную информацию о подключении.
