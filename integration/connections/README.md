# Подключения

Перед тем как использовать в сценариях узлы [взаимодействия с SOAP-сервисами](./../../processors/integration/soap-request.md)/[REST-сервисами](./../../processors/integration/rest-request.md) и [импорта](./../import/README.md)/[экспорта](./../export/README.md) из бизнес-приложений, хранилищ данных, баз данных или иных источников, в [пакете](../../interface/packages.md) необходимо создать подключение к источнику данных. Подключение содержит в себе все необходимые параметры для соединения с источником данных, такие как логин/пароль, расположение источника и др. Созданное подключение в дальнейшем может использоваться в пакете многократно.

## Настройка подключения

Для каждого модуля в составе пакета можно настроить свой список подключений. Для создания/редактирования подключений необходимо отобразить в панели навигации структуру пакета и выбрать пункт *Подключения* соответствующего модуля (см. рисунок 1).

![Выбор пункта "Подключения" в панели навигации](./readme-1.png)

В результате в левой части экрана в виде дерева отобразится перечень возможных для создания подключений (см. рисунок 2, область 1) — дерево классов подключений.

Подключение можно создать двумя способами:

* перетащить нужное подключение из дерева (1) в область подключений (2);
* дважды кликнуть по выбранному подключению в дереве.

В области подключений появится новое подключение (3), и откроется диалог редактирования параметров подключения.

![Создание нового подключения](./readme-2.png)

После того как требуемые параметры будут заданы, подключение может быть протестировано.

Управление подключениями осуществляется с помощью панели инструментов (4):

* ![](./../../images/icons/common/toolbar-controls/arrow-rr_default.svg) Показать дерево коннекторов
* ![](./../../images/icons/common/toolbar-controls/arrow-ll_default.svg) Скрыть дерево коннекторов
* ![](./../../images/icons/common/toolbar-controls/tile_default.svg) Крупная плитка
* ![](./../../images/icons/common/toolbar-controls/table_default.svg) Таблица — отображение в виде таблицы.
* ![](./../../images/icons/common/toolbar-controls/group-list_default.svg) Группировать список — включение группировки списка по видам подключений.
* ![](./../../images/icons/common/toolbar-controls/setup_default.svg) Настроить подключение… — открывает мастер настройки подключения.
* ![](./../../images/icons/common/toolbar-controls/access-rights_default.svg) Настроить [модификатор доступа](./../../workflow/access-modifier.md) — открывает окно настройки модификатора доступа.
* ![](./../../images/icons/common/toolbar-controls/clone_default.svg) Клонировать подключение — добавляет новое подключение на основе выбранного и выделяет его. При клонировании копируются все настройки исходного подключения. Кнопка доступна, если выделено только одно подключение.
* ![](./../../images/icons/common/toolbar-controls/delete_default.svg) Удалить подключение… — удаляет подключение из общего списка подключений.
* Тестировать — тестовая активация подключения (неактивна, если подключение не выбрано, либо уже активировано).
* ![](./../../images/icons/common/toolbar-controls/test-connection_default.svg) Активировать подключение — позволяет активировать/деактивировать выбранное подключение.

Навигация по подключениям осуществляется с помощью инструментов:

* ![](./../../images/icons/common/toolbar-controls/zoom_default.svg) Искать — поиск подключения по имени/пути (возможен поиск в разных группах).
* ![](./../../images/icons/common/toolbar-controls/filter_default.svg) Фильтровать список — фильтрация по группам/меткам/пути подключения.
* ![](./../../images/icons/common/toolbar-controls/sort-asc_default.svg) Сортировать список — сортировка подключений по убыванию/возрастанию.

Вышеперечисленные команды можно выполнить через контекстное меню, которое вызывается при нажатии правой кнопки мыши по подключению. При этом добавляются дополнительные действия:

* ![](./../../images/icons/common/toolbar-controls/edit_default.svg) Переименовать подключение… — позволяет редактировать метку подключения.
* ![](./../../images/icons/common/toolbar-controls/stop_default.svg) Деактивировать все — деактивирует все активные подключения.

Доступны горячие клавиши, дублирующие некоторые перечисленные команды:

* %kbd F3 % — активировать подключение
* %kbd Shift F3 % — тестировать подключение
* %kbd F2 % — переименовать подключение
* %kbd Alt G % — группировка списка
* %kbd Ctrl D % — фильтровать список
* %kbd Enter % — настроить подключение
* %kbd Delete % — удалить подключение

> **Важно:** Для организации подключений к некоторыми источниками, например, к некоторым базам данных, необходимо наличие установленного клиента этой СУБД, либо клиентских библиотек той же разрядности, что и разрядность приложения/сервера Loginom.
